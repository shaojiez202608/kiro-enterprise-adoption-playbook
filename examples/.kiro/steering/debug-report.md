# Debug report template

Use this file by typing `#debug-report` in chat (it also appears as a slash command).

When I attach this file, I am reporting a problem. Before proposing a fix:

1. Read the context I attached (for example `#terminal`, `#problems`, `#git diff`, or a specific `#file`).
2. Restate the symptom in one sentence and list the evidence you used.
3. Propose the smallest change that addresses the cause, then run the relevant tests.
4. If the problem is in the frontend demo, follow the frontend verification steps in `frontend-verification.md`.

Reply in the same language I used.
